# Hangman Game

A simple text-based Hangman game developed using Python.

## Features

- Uses 5 predefined words
- Randomly selects a word for each game
- Player guesses one letter at a time
- Maximum 6 wrong guesses are allowed
- Displays the guessed letters and remaining attempts

## Technologies Used

- Python
- Jupyter Notebook

## How to Play

1. Run the notebook.
2. Guess one letter at a time.
3. Try to guess the complete word before making 6 wrong guesses.
